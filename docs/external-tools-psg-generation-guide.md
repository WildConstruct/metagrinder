# External Tools PSG Asset Generation Guide

## Overview

This guide explains how external tools like ChatGPT, Claude, and other AI assistants can generate assets compatible with the PSG (Prompt Spaghetti Graph) file format. The PSG format is a JSON-based structure that can be easily generated by AI systems when given proper instructions.

## PSG File Format Quick Reference

### Basic Structure

The PSG format is a JSON file with the `.psg` extension containing:

```json
{
  "fileType": "psg",
  "formatVersion": "2.0.0",
  "metadata": {
    "name": "Project Name",
    "description": "Description",
    "createdAt": "2025-08-01T10:00:00.000Z",
    "lastModified": "2025-08-01T10:00:00.000Z",
    "author": "Author Name"
  },
  "graph": {
    "nodes": [],
    "edges": []
  }
}
```

## How to Request PSG Generation from AI Tools

### 1. ChatGPT/Claude Instructions

When prompting an AI to generate PSG files, provide this template:

```
Please generate a PSG file (JSON format) for a [describe your use case].

The file should follow this structure:
- fileType: "psg"
- formatVersion: "2.0.0"
- metadata with name, description, and timestamps
- graph with nodes and edges arrays

Node types available:
- TextBlock: Simple text content
- WeightedChoice: Random selection with weights
- Concat: Concatenate multiple inputs
- Output: Final output node
- Include: Reference other nodes
- SetVariable/GetVariable: Variable management

Each node needs:
- id: unique identifier
- type: node type
- position: {x, y} coordinates
- data: type-specific content

Edges connect nodes with:
- id: unique identifier
- source: source node id
- target: target node id
```

### 2. Example Prompts for Common Use Cases

#### Character Name Generator

```
Create a PSG file for a fantasy character name generator with:
- A WeightedChoice node for first names (mix of common and exotic)
- A WeightedChoice node for surnames
- A Concat node to combine them
- An Output node to display the result
```

#### Story Prompt Generator

```
Generate a PSG file for a creative writing prompt generator including:
- WeightedChoice nodes for: character type, setting, conflict, and goal
- A Concat node that combines them into a coherent prompt
- Variables to store selected choices
- An Output node with the final prompt
```

## Node Types and Their JSON Structure

### TextBlock Node

```json
{
  "id": "text-1",
  "type": "TextBlock",
  "position": { "x": 100, "y": 100 },
  "data": {
    "value": "Your text content here"
  }
}
```

### WeightedChoice Node

```json
{
  "id": "choice-1",
  "type": "WeightedChoice",
  "position": { "x": 200, "y": 100 },
  "data": {
    "choices": [
      { "text": "Option 1", "weight": 50 },
      { "text": "Option 2", "weight": 30 },
      { "text": "Option 3", "weight": 20 }
    ]
  }
}
```

### Concat Node

```json
{
  "id": "concat-1",
  "type": "Concat",
  "position": { "x": 300, "y": 200 },
  "data": {
    "separator": " ",
    "prefix": "",
    "suffix": ""
  }
}
```

### Output Node

```json
{
  "id": "output-1",
  "type": "Output",
  "position": { "x": 400, "y": 300 },
  "data": {
    "template": "Generated result: {input}"
  }
}
```

## Integration Workflow

### 1. Generate PSG Content

Ask the AI tool to generate PSG JSON content following the specifications above.

### 2. Save as .psg File

Copy the generated JSON and save it with a `.psg` extension.

### 3. Import into Prompt Spaghetti

Use the application's import feature to load the generated PSG file:

- Open the File Browser
- Click "Open" or "Import"
- Select your generated .psg file
- The graph will load in the editor

### 4. Test and Refine

- Use the Preview feature to test generation
- Adjust weights and content as needed
- Save changes back to the PSG file

## Best Practices for AI-Generated PSG Files

### 1. Validation

Always validate generated JSON:

- Ensure unique IDs for all nodes and edges
- Verify source/target nodes exist for all edges
- Check that required fields are present

### 2. Positioning

Suggest logical positions:

- Input nodes on the left (x: 100-200)
- Processing nodes in the middle (x: 300-400)
- Output nodes on the right (x: 500-600)
- Space nodes vertically by 100-150 units

### 3. Naming Conventions

Use clear, descriptive IDs:

- `first-name-choice` instead of `node-1`
- `combine-elements` instead of `concat-1`
- `final-output` instead of `output`

### 4. Documentation

Include in metadata:

- Clear name and description
- Author attribution (e.g., "Generated by ChatGPT")
- Creation/modification timestamps

## Advanced Features

### Variables

For stateful generation:

```json
{
  "id": "set-character-name",
  "type": "SetVariable",
  "data": {
    "variableName": "characterName"
  }
}
```

### Conditional Logic

Using variables for conditional outputs:

```json
{
  "id": "conditional-output",
  "type": "Output",
  "data": {
    "template": "The character {characterName} enters the {location}."
  }
}
```

### Nested Structures

Complex generators can include:

- Multiple WeightedChoice nodes feeding into each other
- Variable storage for maintaining context
- Include nodes to reference sub-graphs

## Troubleshooting

### Common Issues

1. **Invalid JSON**: Ensure proper comma placement and bracket matching
2. **Missing Edges**: Verify all nodes are connected
3. **Duplicate IDs**: Each node and edge must have a unique ID
4. **Type Mismatches**: Ensure node types are spelled correctly

### Validation Tools

Use JSON validators before importing:

- JSONLint (jsonlint.com)
- JSON Schema Validator
- Built-in IDE JSON validation
